# ASTRA – Desktop Voice Assistant

<p align="center">
  <strong>A Python-based desktop voice assistant that automates everyday computer tasks using speech recognition and voice commands.</strong>
</p>

---

## Features

- 🎤 Voice-controlled desktop assistant
- 🗣️ Speech Recognition
- 🔊 Text-to-Speech responses
- 💻 Desktop application launcher
- 🌐 Website automation
- 🎵 YouTube song playback
- 🔉 System volume control
- 📸 Screenshot capture
- 💾 Persistent memory
- ⚡ System control (Shutdown, Restart, Lock, Sleep)
- 📝 Command logging
- 🤖 AI-ready modular architecture

# Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/astra-ai-desktop-assistant.git
```

Move into the project

```bash
cd astra-ai-desktop-assistant
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run ASTRA

```bash
python main.py
```
